# 🍏 RealDub для macOS (Apple Silicon / Intel)

Офлайн перекладач мовлення в реальному часі для MacBook та Mac:
- 🎧 **Звук Mac (Zoom, Teams, Google Meet, YouTube):** миттєвий переклад **EN → UK**
- 🎤 **Мікрофон:** переклад вашої мови **UK → EN** (+ озвучення англійською за бажанням)
- ⚡ **Офлайн:** працює повністю локально на процесорі Apple Silicon (M1/M2/M3/M4) без надсилання даних в інтернет.

---

## 🚀 Швидкий старт

### 1. Встановлення
Відкрийте Термінал у цій папці та виконайте:
```bash
chmod +x install.sh start.sh
./install.sh
```
*Скрипт автоматично створить віртуальне оточення, встановить залежності та завантажить моделі ШІ.*

### 2. Запуск
```bash
./start.sh
```

## 🎧 Як налаштувати звук конференцій на Mac (BlackHole)

В операційній системі macOS з міркувань безпеки програми не можуть напряму перехоплювати звук динаміків. Для цього використовується безкоштовний віртуальний кабель **BlackHole 2ch**.

1. **Встановлення BlackHole** (якщо не встановився автоматично):
   ```bash
   brew install blackhole-2ch
   ```
2. **Щоб ви одночасно чули звук у навушниках і програма перекладала його:**
   - Відкрийте стандартну програму Mac: **Audio MIDI Setup** (Налаштування Audio-MIDI).
   - Знизу зліва натисніть **`+`** $\to$ **Create Multi-Output Device** (Створити багатовивідний пристрій).
   - Поставте галочки навпроти:
     1. Ваших навушників або динаміків Mac (*MacBook Speakers / AirPods*).
     2. **BlackHole 2ch**.
   - У верхньому меню Mac (значок звуку) виберіть виводом цей створений пристрій (**Multi-Output Device**).
3. У **RealDub** натисніть кнопку **`🎧 Звук Mac (BlackHole)`** — переклад почнеться автоматично!

## 🛠 Керування оверлеєм
| Елемент | Призначення |
|---|---|
| `🎧 Звук Mac (BlackHole)` | Переклад того, що звучить у конференції або відео (EN→UK) |
| `🎤 Мікрофон UK→EN` | Переклад вашої мови у мікрофон на англійську |
| `🔊 Озвучувати` | Синтез англійського перекладу мовлення через Piper TTS |
| Поле вводу | Напишіть українською $\to$ переклад англійською (+ озвучення) |
| `🧹` | Очистити вікно субтитрів |
| `✕` | Закрити програму |

*Вікно можна вільно перетягувати за будь-яке місце лівою кнопкою миші, а правий нижній куточок змінює розмір.*
