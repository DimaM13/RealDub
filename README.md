# 🌐 RealDub v2.1.1 — офлайн перекладач мовлення в реальному часі для Windows

Зручний та легкий оверлей поверх усіх вікон:
- 🎧 **Звук комп'ютера (Zoom, Teams, Google Meet, YouTube):** миттєвий переклад **англійська → українська**.
- 🎤 **Мікрофон:** переклад вашої мови **українська → англійська** з можливістю озвучення голосом.
- ⚡ **Повністю офлайн:** усі моделі ШІ працюють локально на вашому комп'ютері (NVIDIA GPU або процесор) без передачі звуку в інтернет.
- 🔄 **Автооновлення:** підтримка перевірки та оновлення програми напряму з GitHub в 1 клік.

---

## 🚀 Встановлення (в 1 клік)

1. Запустіть файл **`setup.bat`** (або `install.bat`).
2. Відкриється графічний майстер встановлення:
   - Оберіть папку для встановлення (за замовчуванням `%LOCALAPPDATA%\RealDub`).
   - Поставте галочки для створення ярликів на **Робочому столі** та в **меню «Пуск»**.
   - Натисніть **«Встановити»**.
3. Інсталятор автоматично налаштує віртуальне оточення, встановить залежності з оптимізацією під відеокарту NVIDIA та завантажить/перевірить моделі ШІ.
4. Після завершення натисніть **«Завершити»** — RealDub запуститься автоматично!

## 🔄 Оновлення через GitHub

RealDub автоматично перевіряє наявність нових версій на GitHub при запуску:
- Якщо вийшла нова версія, кнопка **`🔄`** підсвічується зеленим кольором.
- Ви можете також натиснути **`🔄`** у будь-який момент для ручної перевірки.
- Оновлення завантажує лише оновлений код програми, зберігаючи всі ваші локальні налаштування (`config.json`) та завантажені моделі (`models/`).

---

## 🎙️ Щоб співрозмовники в Zoom / Teams чули озвучення вашого голосу
Встановіть безкоштовний віртуальний кабель [VB-Audio Virtual Cable](https://vb-audio.com/Cable/):
1. У файлі `config.json` вкажіть: `"tts_output_device": "CABLE Input"`.
2. У Zoom / Teams / Discord оберіть мікрофоном `CABLE Output`.

## 🧠 Використовувані моделі
- **Розпізнавання мови:** Faster-Whisper `small` (NVIDIA CUDA / CPU, оптимізований float16/int8).
- **Переклад:** NLLB-200 600M (CTranslate2, висока якість синтаксису).
- **Озвучення:** Piper TTS (природні голоси en/uk).
