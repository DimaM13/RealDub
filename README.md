# 🌐 RealDub v2.0.0 — офлайн перекладач мовлення в реальному часі

Легкий оверлей поверх усіх вікон: слухає звук комп'ютера (конференції, відео) і показує переклад **англійська → українська**, а також слухає ваш мікрофон і перекладає **українська → англійська** (з озвученням за бажанням). Працює **повністю офлайн**.

## Встановлення
1. Запустіть `install.bat` (потрібен інтернет лише цей один раз — завантажаться моделі ~0,8 ГБ).
2. Далі запускайте `start.bat` — інтернет не потрібен.

## Керування
| Кнопка | Дія |
|---|---|
| 🎧 Звук ПК EN→UK | переклад того, що звучить у комп'ютері |
| 🎤 Мікрофон UK→EN | переклад вашої мови |
| 🔊 Озвучувати | англійський переклад вашої мови промовляється голосом |
| Поле вводу | напишіть українською → переклад англійською (+ озвучення) |

Вікно можна перетягувати мишею, розмір — за куточок справа знизу.

## Щоб співрозмовники в Zoom/Teams/Discord чули озвучення
Встановіть безкоштовний [VB-Audio Virtual Cable](https://vb-audio.com/Cable/), у `config.json` вкажіть `"tts_output_device": "CABLE Input"`, а в конференції оберіть мікрофоном `CABLE Output`.

## Моделі
- Розпізнавання: Whisper `small` (faster-whisper, відеокарта або процесор)
- Переклад: NLLB-200 600M (CTranslate2), запасний — OPUS-MT / Argos
- Озвучення: Piper

Налаштування — у `config.json` (модель `base` — швидше, `medium` — точніше).
