# 🌐 RealDub v2.2.1 — автономний офлайн перекладач мовлення для Windows

Зручний та легкий оверлей поверх усіх вікон із підтримкою вибору моделей **Whisper Medium / Small** та окремим словниковим перекладачем для введених слів:
- 🎧 **Звук комп'ютера (Zoom, Teams, Google Meet, YouTube, лекції, ігри):** миттєвий переклад **англійська → українська**.
- 🎤 **Мікрофон:** переклад вашої мови **українська → англійська** з можливістю озвучення голосом.
- ✍️ **Розумне поле вводу (укр ↔ англ):** для окремих слів використовує спеціалізований словниковий перекладач із підбором синонімів, а для речень — контекстну нейромережу.
- 🧠 **Вибір моделі Whisper у вікні (`🎯 Medium` / `⚡ Small`):** за замовчуванням працює точна модель **Medium**; перемикання між `Medium` та `Small` відбувається миттєво та повністю офлайн.
- ⚡ **100% автономна робота без інтернету:** усі моделі розпізнавання, перекладу та озвучення працюють локально на вашому ПК.

---

## 📦 Готовий установник для передачі іншим людям (`RealDub_Installer`)

У папці **`RealDub_Installer`** знаходиться повний автономний комплект для встановлення на будь-який комп'ютер із Windows:
- **`RealDub_Setup.exe`** — графічний установник із фірмовою іконкою RealDub.
- **`data/`** — папка з програмою, виконуваним файлом `RealDub.exe` та **вже завантаженими моделями ШІ** (`whisper-medium`, `whisper-small`, `nllb-600m`, словниковими моделями `mt-en-uk` / `mt-uk-en` та голосами `Piper TTS`).

Щоб передати програму іншій людині — просто скиньте їй папку **`RealDub_Installer`** (або запакуйте її в ZIP-архів). У ній немає жодних особистих даних чи прив'язок до акаунтів. Достатньо запустити **`RealDub_Setup.exe`** та натиснути **«Встановити»**!

## 🎮 Керування оверлеєм

| Кнопка / Елемент | Призначення |
|---|---|
| `🎧 Звук ПК EN→UK` | Захоплення та переклад звуку конференцій, дзвінків або відео (вмикається автоматично) |
| `🎤 Мікрофон UK→EN` | Розпізнавання та переклад вашого мовлення з мікрофона |
| `🔊 Озвучка` | Озвучення англійського перекладу голосом (Piper TTS) |
| `🎯 Medium (Точна) ▾` | Вибір моделі розпізнавання Whisper (`Medium` або `Small`) |
| `A−` / `A+` | Зменшити або збільшити розмір шрифту (зберігається автоматично) |
| `📋` | Скопіювати останній переклад у буфер обміну |
| `🔄` | Перевірити та встановити оновлення з GitHub в 1 клік |
| `🧹` | Очистити історію субтитрів |
| `✕` | Закрити програму та повністю вивантажити моделі з пам'яті (ОЗП/VRAM) |
| Поле вводу знизу | Введіть слово або речення (українською чи англійською) $\to$ точний переклад + синоніми |
